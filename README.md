# Masafir

Masafir is a modern fashion e-commerce platform designed to provide a premium shopping experience for customers who value style, identity, and lifestyle-driven apparel. The brand blends South Asian heritage with contemporary streetwear aesthetics, creating a unique digital presence that feels both premium and culturally rooted.

The platform includes essential online store features such as product browsing, category-based shopping, cart management, checkout flow, account access, and brand storytelling. Users can explore collections, view product details, check sizes, and complete purchases in a smooth and responsive interface.

Built with a React and Vite frontend and a Django backend, Masafir offers a scalable architecture suitable for a real-world online retail brand. The design emphasizes minimal luxury, clean typography, and a strong visual identity that aligns with the brand's values and target audience.

## Key Features

- Modern and responsive storefront
- Product catalog and category browsing
- Product detail pages with size selection
- Shopping cart and checkout flow
- User authentication and account support
- Brand discovery and storytelling pages
- Mobile-friendly navigation
- Clean, premium fashion-focused UI

## Tech Stack

**Frontend:** React, Vite, Redux Toolkit, React Router  
**Backend:** Django, Django REST Framework  
**Database:** SQLite (with support for other databases)  
**Media Storage:** Cloudinary  
**Styling:** Custom CSS and modern design system
